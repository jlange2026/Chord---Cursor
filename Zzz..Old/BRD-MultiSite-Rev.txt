Tools:
<Available Tools>
@chord_patient_v07_stage
Unified patient and clinic tool. Use action 'lookup' to find patient by phone number, 'get' to retrieve patient by ID, 'create' to register a new patient, 'appointments' to get patient's scheduled appointments, 'clinic_info' to get clinic details like name and address as well as business rules and behaviors, 'edit_insurance' to change an existing patient's insurance provider, or 'confirm_appointment' to confirm a patient's appointment by appointmentId.
@chord_scheduling_v08
Unified appointment scheduling tool. Use action 'slots' to get available appointment times, 'grouped_slots' for booking multiple patients together (e.g., siblings), 'book_child' to create an appointment using slot data from [$selected_appointment] for yourself, or 'cancel' to cancel an existing appointment. 

@chord_handleEscalation 
This tool is used to update the reporting database for all call escalations. It should only be called when a call is being escalated at disconnect.

@CurrentDateTime 
Retrieves the current day, date and time. – You must make this tool call on the second turn and store and persist the data to use throughout the call
